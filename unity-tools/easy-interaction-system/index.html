WHY EASY INTERACTION SYSTEM?

Spend less time rebuilding basic interaction logic

Easy Interaction System is designed to provide a reusable foundation for common first-person interactions in Unity projects.

01

Reusable

Use the same interaction foundation across multiple scenes instead of rebuilding the system every time.

02

Inspector Friendly

Configure prompts, references, colors, interaction distance and events directly from the Unity Inspector.

03

Ready to Test

A demo setup helps developers quickly understand how the system works before integrating it.

FEATURES

Current Features

These are the current confirmed systems included in Easy Interaction System.

RAYCAST

Raycast Interaction

Detect interactive objects directly from the player camera.

UI

Interaction Prompts

Display contextual interaction text when the player targets an interactive object.

DOORS

Interactive Doors

Ready-to-use door interactions for opening and closing objects.

BUTTONS

Interactive Buttons

Reusable interactive buttons can trigger configured gameplay actions.

STATE

State Indicators

Visual indicators can display object states such as open or closed.

EVENTS

Unity Events

Connect button interactions to additional actions directly through the Inspector.

INSPECTOR

Inspector Configuration

Configure interaction distance, prompts, references, colors and events directly in Unity.

PREFABS

Reusable Prefabs

Ready-made prefabs simplify moving and reusing the interaction system between scenes.

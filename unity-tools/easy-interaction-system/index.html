What is Easy Interaction System?

Easy Interaction System is a reusable Unity interaction framework that allows developers to build and configure common gameplay interactions without rebuilding the same logic for every project.

Features

Current confirmed functionality included in the system.

RAYCAST

Raycast Interaction

Detect interactive objects directly from the player camera.

UI

Interaction Prompts

Show contextual interaction text when the player looks at an interactive object.

OBJECTS

Interactive Doors

Ready-to-use door interactions for opening and closing gameplay objects.

OBJECTS

Interactive Buttons

Trigger actions through reusable interactive button components.

STATE

State Indicators

Visual indicators can reflect object states such as open and closed.

EVENTS

Unity Events

Connect button interactions to additional gameplay actions through the Inspector.

INSPECTOR

Inspector Configuration

Configure prompts, interaction distance, references, colors and events directly in Unity.

PREFABS

Reusable Prefabs

Ready-made prefabs make it easier to move the system between scenes and projects.

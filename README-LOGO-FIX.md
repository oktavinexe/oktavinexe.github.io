# Oktavin.exe — official logo fix

This update replaces the temporary CSS-drawn symbol with the official uploaded Oktavin.exe artwork on all site pages and also makes it the browser favicon. No new logo was generated.

## Deploy
1. Extract ZIP.
2. Open the root of `oktavinexe.github.io` GitHub repository.
3. Click **Add file → Upload files**.
4. Drag all files and folders from this folder (not the folder itself).
5. Commit changes.
6. Open site in a new tab and press Ctrl+F5 to refresh cached CSS.

Other pages, content, and files in the repo are retained.
